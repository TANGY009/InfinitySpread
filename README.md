# InfinitySpread

Ever wanted to flood your entire world with a single water block?
Or turn a hill into a volcano using one lava bucket?

InfinitySpread simply whispers:

“Chaos is efficient. Reality is optional.” — InfinitySpread

## Requirements

* LeviLauncher — <https://github.com/LiteLDev/LeviLaunchroid>
* libInfinitySpread mod installed

## Installation

1. Download libInfinitySpread from [Releases](https://github.com/TANGY009/InfinitySpread/releases) or [GitHub Actions](https://github.com/TANGY009/InfinitySpread/actions)
2. Install LeviLauncher
3. Add libInfinitySpread mod in LeviLauncher
4. Launch Minecraft through LeviLauncher
